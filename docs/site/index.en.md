# A visual editor for SPIP

**Write and format your text without typing SPIP shortcuts by hand.**
The visual editor replaces the usual text area in SPIP fields configured to use it.
It preserves your content and your site's rendering: switching to the visual editor does not
require converting existing articles.

You can still create links to articles, notes, tables, and models. The **Source** button lets you
return to SPIP syntax at any time.

## Where to start

1. [Install the plugin](installer.md) from a ZIP archive or via FTP.
2. [Open an article and get started](premiers-pas.md).
3. Explore the [formatting tools](utiliser/mise-en-forme.md) and
   [SPIP content tools](utiliser/contenus-spip.md).

If you manage the site, read about [configuration](configurer.md). If you develop plugins, the
[FAQ extension tutorial](developper/faq.md) starts from a working example.

!!! info "Who is this documentation for?"
    **Install**, **Getting started**, and **Use the editor** are for people who manage or write
    content for a SPIP site. Technical details are under **Understand** and **Develop**.
