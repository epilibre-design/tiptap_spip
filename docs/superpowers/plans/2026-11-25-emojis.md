# Emojis Unicode et sélecteur — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Proposer les emojis du catalogue anglais du picker dès un caractère après `:`, et le sélecteur complet depuis un bouton ou « Plus… », avec insertion de texte Unicode.

**Architecture:** Un build copie le JSON anglais original et génère son manifeste de version. Le fournisseur inline lit ce JSON et utilise le socle déjà fusionné ; `emoji-picker-element` lit la même URL dans une base IndexedDB isolée et fournit son interface native dans l’enveloppe commune.

**Tech Stack:** JavaScript ESM, Tiptap 3.31.4, `emoji-picker-element` 1.29.1 et `emoji-picker-element-data` 1.8.0, SPIP/PHP, esbuild, Vitest, Playwright/axe, PHPUnit.

**Spec:** [Emojis](../specs/2026-11-25-emojis-design.md), [socle](../specs/2026-11-25-menu-suggestions-design.md) et [plan préalable](2026-11-25-menu-suggestions.md). Les versions ci-dessus sont celles étudiées ; les verrouiller exactement, sans mise à jour implicite pendant cette livraison.

## Global Constraints

- Livraison séparée après fusion du socle dans `main`, avec sa propre entrée CHANGELOG ; pas de plugin SPIP distinct.
- Aucun nœud emoji, aucune dépendance `@tiptap/extension-emoji`, aucun changement de parseur/sérialiseur et aucune conversion automatique des shortcodes/émoticônes.
- Catalogue unique : copie sans transformation de `en/emojibase/data.json` ; URL locale absolue fournie par PHP, pas de CDN. Noms, shortcodes et tags anglais, sans alias français ou multilinguisme de recherche.
- Inline : seuil **1**, motif entier `/^[a-z0-9_+=-]+$/i`, préfixes U+0020 ou `\n` ou véritable début de bloc ; pas de U+00A0/U+202F. Espace ou caractère interdit ferme sans mutation.
- **6** résultats et « Plus… » seulement au-delà ; aucun choix actif spontané ; aucun second filtrage implicite.
- Classement : shortcode exact, shortcode préfixe, annotation/tag exact, annotation/tag préfixe, inclusion. Égalités par `order`, puis position JSON ; alias correspondant affiché, titre interne sans `:`.
- Picker natif : seuil de recherche **2** conservé ; données identiques, moteurs indépendants. Pas de préremplissage privé du champ de recherche.
- Le picker exige `HTMLElement` dès son import. Importer `PickerEmoji.js` uniquement depuis l’interface navigateur ; jamais depuis `editor/extensions.js`, `catalogue.js` ou `fournisseur.js`. Le fournisseur ouvre le panneau par `ui.openEmoji`, sans importer son adaptateur DOM.
- Base `en-tiptap-spip-<version>` et URL issues d’un même manifeste généré. Nouvelle version = nouvelle base et remise à zéro des favoris/teinte ; pas de migration ou suppression automatique des anciennes bases.
- Surcoût JS/CSS cumulé avec le socle : **40 Kio gzip maximum** ; JSON : **80 Kio gzip maximum** ; `gzip -n -6 -c`. Référence JSON étudiée : **74 647 octets**, 1 923 entrées, 439 662 octets bruts.
- Focus initial : accès ciblé au champ Shadow DOM autorisé, repli interne entre sentinelles. Échap traité en remontée après les teintes ; capture plein écran passive.
- Un seul `emoji-click` accepté par ouverture, plage/contexte revalidés ; événement retardé après fermeture ignoré. Chaque essai de chargement utilise un nouvel élément.
- Unicode ordinaire, marks et séquences VS15/VS16/ZWJ/teintes préservées. Ne pas ajouter de raccourci global, `Mod-Shift-E` reste au mode source.

## Review Focus

1. Picker en erreur dans une note en plein écran : repli → Tab « Réessayer » → Tab sortie avant, et Maj+Tab dans le bon sens — tâche 1.
2. Liste de teintes ouverte : premier Échap ferme les teintes, suivant ferme le picker, parent et plein écran préservés — tâche 1, avant le reste de l’intégration.
3. Double-clic ou choix asynchrone après annulation/destruction : aucune insertion multiple ou tardive — tâches 1/3.
4. Curseur au milieu de `:he|art` et transactions pendant l’ouverture : remplacer uniquement la plage suivie encore valide, garder le suffixe — tâches 3/4.
5. Emoji transformé en entité par MySQL `utf8` : préserver la source reçue, sans double échappement ou décodage global ; déclencheur refusé immédiatement après cet atome — tâche 5.
