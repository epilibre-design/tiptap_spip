# Hôtes de l'éditeur (lot L2b) — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal :** l'éditeur s'accroche à d'autres hôtes que les formulaires d'édition de l'espace privé — crayons du site public, formulaires déclarés par le pipeline `tiptap_spip_contextes`, réglages sans objet, tout textarea marqué `data-tts-*` — avec ses services serveur (rendus après le formulaire hôte ou chargés à la demande), un cycle de vie sans fuite et les styles adaptés à l'hôte.

**Architecture :** côté serveur, `formulaire_fond` traite les `editer_*` et les formulaires déclarés (contexte objet/id/champs, `data-tts-toolbar` posé sur leurs textareas) ; la page `tiptap_spip_services` rend à la demande le formulaire de services d'un contexte (vérifié par `charger()`) ; `insert_head` charge l'éditeur dans le site public si `tiptap_spip/public` vaut `oui`. Côté JS, `src/hosts/contexte.js` déduit le contexte d'un textarea (`data-tts-*`, crayon, sans objet), `src/hosts/aLaDemande.js` charge le formulaire de services ; les caches acceptent des services qui arrivent plus tard ; le pont sérialise sur `form-pre-serialize` (jquery.form).

**Tech Stack :** inchangée ; plugin Crayons 3.5.1 (`https://git.spip.net/spip-contrib-extensions/crayons.git`) dans le site jetable ; plugin de test `tests/e2e/plugin/tts_test`.

**Specs de référence :** `docs/specs/02-architecture.md` §5–§6, `docs/specs/08-tests-recette.md` (« Hôtes »), Q9 de `docs/specs/09-lots-roadmap.md`.

## Global Constraints

- Mêmes contraintes que les lots précédents.
- Options lues en métas jusqu'à la page de configuration (lot L5) : `tiptap_spip/public` (charger l'éditeur dans le site public) et `tiptap_spip/crayons` (équiper les crayons), `non` par défaut — Q9 tranchée : Crayons sur option.
- Comportements vérifiés pendant la préparation (ne pas « corriger ») :
  - dans le site public, `autoriser()` n'est pas chargé d'office : le formulaire de services doit inclure `inc/autoriser` (sans cela, la page de services répond 503 et le crayon reste sans services ; contrôlé : le test « crayon public » échoue sans l'inclusion) ;
  - Crayons : formulaire `form.formulaire_crayon` ajouté à la fin de `<body>` dans `div.crayon-html`, retiré à l'enregistrement comme à l'annulation ; textarea `textarea.crayon-active` nommé `content_<clé>_<champ>` ; champ caché `name_<clé>` = `objet-champ-id` ; `jQuery.spip.triggerAjaxLoad(tous.get())` passe un **tableau** d'éléments ; envoi par jquery.form sur un `.trigger("submit")` jQuery, que l'écouteur `submit` natif ne voit pas (événement `form-pre-serialize`) ;
  - SPIP ne descend pas dans un dossier de plugin une fois son `paquet.xml` trouvé : le plugin de test placé dans `tests/e2e/plugin/` n'est jamais découvert sur un site réel ;
  - avec l'option `tiptap_spip/public`, le formulaire de forum d'un article public (`textarea[name=texte]`) est équipé lui aussi (barre `forum` au lot L5, spec 09 Q7).
- Hors de ce plan : page de configuration, barres par hôte (lot L5), SPIP 5.

`tiptap_spip_pipelines.php` :

```php
<?php

/**
 * Pipelines du plugin Éditeur visuel pour SPIP.
 */

if (!defined('_ECRIRE_INC_VERSION')) {
	return;
}

/**
 * Configuration, feuilles de style et bundle de l'éditeur, à insérer dans le <head> (SPIP 4).
 * La configuration est calculée avec `prive` dans son contexte : le même squelette sert l'espace
 * privé et le site public sans partager son cache.
 */
function tiptap_spip_head(bool $prive): string {
	$config = recuperer_fond('prive/javascript/_inits/09_tiptap_spip_config.js', ['prive' => $prive ? 'oui' : 'non']);
	$lib = find_in_path('prive/javascript/tiptap_spip.min.js') ?: find_in_path('prive/javascript/tiptap_spip.js');
	if (!$config || !$lib) {
		return '';
	}
	$head = '';
	foreach (['css/tiptap_spip.css', 'css/tiptap_spip_contenu.css'] as $feuille) {
		if ($css = find_in_path($feuille)) {
			$head .= '<link rel="stylesheet" href="' . timestamp($css) . '" type="text/css" />' . "\n";
		}
	}
	$head .= "<script>\n" . $config . "\n</script>\n";
	$head .= "<script type=\"module\">\n"
		. "import { tiptap_spip_init } from '" . protocole_implicite(url_absolue(timestamp($lib))) . "';\n"
		. "tiptap_spip_init();\n"
		. "onAjaxLoad(function () { tiptap_spip_init(this); });\n"
		. "</script>\n";

	return $head;
}

/**
 * Espace privé, SPIP 4. SPIP 5 passe par l'importmap et les scripts prive/javascript/_inits/.
 */
function tiptap_spip_header_prive($flux) {
	if ((int) substr($GLOBALS['spip_version_branche'] ?? '4', 0, 1) >= 5) {
		return $flux;
	}
	return $flux . tiptap_spip_head(true);
}

/**
 * Site public : seulement si la configuration l'active (`tiptap_spip/public`), pour les
 * formulaires publics et Crayons (spec 02 §6).
 */
function tiptap_spip_insert_head($flux) {
	include_spip('inc/config');
	if (lire_config('tiptap_spip/public', 'non') !== 'oui') {
		return $flux;
	}
	return $flux . tiptap_spip_head(false);
}

/**
 * SPIP 5 : déclare le bundle dans l'importmap.
 */
function tiptap_spip_importmap($flux) {
	$flux['data'][] = 'tiptap_spip.js';

	return $flux;
}

/**
 * Champs équipés de l'éditeur pour un objet : un formulaire de services par champ.
 * Le lancement JS équipe le champ texte des formulaires SPIP (spec 02 §6).
 *
 * @return string[]
 */
function tiptap_spip_champs(string $objet): array {
	return ['texte'];
}

/**
 * Contextes des formulaires autres que editer_* qui embarquent l'éditeur (spec 02 §6) : nom du
 * formulaire → fonction qui, à partir des arguments de la balise et du contexte du formulaire,
 * renvoie ['objet' => …, 'id_objet' => …, 'champs' => [...]] (objet vide : mode sans objet), ou
 * null pour ne rien équiper. Les plugins complètent la liste par le pipeline tiptap_spip_contextes.
 *
 * @return array<string, callable>
 */
function tiptap_spip_contextes(): array {
	$contextes = [
		// réglages d'identité du site : descriptif du site, sans objet
		'configurer_identite' => static fn () => ['objet' => '', 'id_objet' => 0, 'champs' => ['descriptif_site']],
	];
	return pipeline('tiptap_spip_contextes', $contextes) ?: $contextes;
}

/**
 * Contexte de l'éditeur pour un formulaire : formulaires d'objet (editer_<objet>), ou déclarés par
 * tiptap_spip_contextes.
 *
 * @return array{objet: string, id_objet: int, champs: string[], marquer: bool}|null  marquer : poser
 *         data-tts-toolbar sur les textareas des champs (le lancement JS ne les reconnaît pas seul)
 */
function tiptap_spip_contexte_formulaire(string $form, array $args, array $contexte): ?array {
	if (str_starts_with($form, 'editer_')) {
		// formulaires d'objet (editer_objet) : SPIP transmet ['type' => objet, 'id' => id] comme args
		$objet = (string) ($args['type'] ?? substr($form, 7));
		$id_objet = intval($args['id'] ?? $args[0] ?? 0);
		return ['objet' => $objet, 'id_objet' => max(0, $id_objet), 'champs' => tiptap_spip_champs($objet), 'marquer' => false];
	}
	$declares = tiptap_spip_contextes();
	if (!isset($declares[$form]) || !is_callable($declares[$form])) {
		return null;
	}
	$c = $declares[$form]($args, $contexte);
	if (!is_array($c) || empty($c['champs'])) {
		return null;
	}
	return [
		'objet' => (string) ($c['objet'] ?? ''),
		'id_objet' => max(0, intval($c['id_objet'] ?? 0)),
		'champs' => array_values(array_map('strval', $c['champs'])),
		'marquer' => true,
	];
}

/**
 * Ajoute après le </form> d'un formulaire équipé (editer_<objet>, ou déclaré par
 * tiptap_spip_contextes) les formulaires de services de l'éditeur, un par champ, reliés au
 * formulaire par un identifiant d'instance aléatoire (spec 02 §5 « Intégration ») : deux formulaires
 * d'édition du même objet dans une page gardent chacun leurs services.
 */
function tiptap_spip_formulaire_fond($flux) {
	$form = $flux['args']['form'] ?? '';
	if ($form === 'tiptap_spip' || !str_contains($flux['data'], '<form')) {
		return $flux;
	}
	$c = tiptap_spip_contexte_formulaire($form, (array) ($flux['args']['args'] ?? []), (array) ($flux['args']['contexte'] ?? []));
	if (!$c) {
		return $flux;
	}
	$services = '';
	foreach ($c['champs'] as $champ) {
		$services .= recuperer_fond('inclure/tiptap_spip_services', [
			'objet' => $c['objet'],
			'id_objet' => $c['id_objet'],
			'champ' => $champ,
		]);
	}
	if (trim($services) === '') {
		return $flux;
	}
	$instance = 'tts-' . bin2hex(random_bytes(6));
	$data = preg_replace('/<form\b/i', '<form data-tts-instance="' . $instance . '"', $flux['data'], 1);
	if ($c['marquer']) {
		foreach ($c['champs'] as $champ) {
			$data = preg_replace(
				'/<textarea\b(?![^>]*\bdata-tts-toolbar=)(?=[^>]*\bname=([\'"])' . preg_quote($champ, '/') . '\1)/i',
				'<textarea data-tts-toolbar="minimale"',
				$data
			);
		}
	}
	$flux['data'] = $data . str_replace('data-tts-instance=""', 'data-tts-instance="' . $instance . '"', $services);

	return $flux;
}
```

```php
/**
 * Vrai si l'auteur connecté peut utiliser les services pour ce champ.
 * Avec objet : droit de modifier l'objet (de le créer s'il est nouveau) et champ texte de sa table.
 * Sans objet (réglages…) : droit de prévisualiser les modèles.

function tiptap_spip_autoriser_services(string $objet, $id_objet, string $champ): bool {

		return false;
	}

		? autoriser('modifier', $objet, intval($id_objet))

function formulaires_tiptap_spip_charger_dist($objet = '', $id_objet = 0, $champ = 'texte') {

		return false;
	}
	return [
		'operation' => '',
		'modele' => '',
		'cibles' => '',
		'q' => '',
		'objets' => '',
		'editable' => true,
	];
}

function formulaires_tiptap_spip_verifier_dist($objet = '', $id_objet = 0, $champ = 'texte') {
	// verifier() passe avant charger() au POST : l'autorisation est refaite ici
	if (!tiptap_spip_autoriser_services((string) $objet, $id_objet, (string) $champ)) {
		return ['message_erreur' => _T('tiptap_spip:erreur_autorisation')];
	}
	$erreurs = [];
	switch (_request('operation')) {
		case 'previsu_modele':
			$modele = (string) _request('modele');
			if (mb_strlen($modele) > 2000 || !tiptap_spip_est_modele($modele)) {
				$erreurs['modele'] = _T('tiptap_spip:erreur_modele');
			} elseif (!tiptap_spip_modele_existe(tiptap_spip_nom_modele($modele))) {
				$erreurs['modele'] = _T('tiptap_spip:erreur_modele_inconnu');
			}
			break;
		case 'titre_lien':
			if (tiptap_spip_liste(_request('cibles'), 50, 500) === null) {
				$erreurs['cibles'] = _T('tiptap_spip:erreur_cibles');
			}
			break;
		case 'rechercher':
			$q = trim((string) _request('q'));
			if (mb_strlen($q) < 2 || mb_strlen($q) > 100) {
				$erreurs['q'] = _T('tiptap_spip:erreur_recherche');
			}
			$objets = tiptap_spip_liste(_request('objets'), 10, 30);
			if ($objets === null || array_diff($objets, tiptap_spip_objets_recherche())) {
				$erreurs['objets'] = _T('tiptap_spip:erreur_objets');
			}
			break;
		default:
			$erreurs['operation'] = _T('tiptap_spip:erreur_operation');
	}
	return $erreurs;
}

/**
 * Titre et URL qu'aura un lien [->cible]. Pour un objet SPIP, le titre n'est donné que si l'auteur
 * peut voir l'objet.

 * @return array{cible: string, titre: ?string, url: ?string, objet: ?string, id: ?int}
 */
function tiptap_spip_titre_lien(string $cible): array {
	include_spip('inc/lien');
	include_spip('base/objets');
	$r = ['cible' => $cible, 'titre' => null, 'url' => null, 'objet' => null, 'id' => null];
	$match = typer_raccourci($cible);
	if ($match && !empty($match[0])) {
		$objet = objet_type($match[0]);
		$id = intval($match[2] ?? 0);
		$r['objet'] = $objet;
		$r['id'] = $id;
		if ($id && autoriser('voir', $objet, $id)) {
			$titre = traiter_raccourci_titre($id, $objet);
			$r['titre'] = $titre ? supprimer_tags(typo($titre['titre'])) : null;
			$r['url'] = generer_objet_url($id, $objet) ?: null;
		}
		return $r;
	}
	if (str_starts_with($cible, '#')) {
		return $r;
	}
	$lien = calculer_url($cible, '', 'tout', '', false);
	if (is_array($lien) && $lien['url'] !== '') {
		$r['titre'] = supprimer_tags((string) $lien['titre']);
		$r['url'] = (string) $lien['url'];
	}
	return $r;
}

/**
 * Objets dont le titre contient $q, visibles par l'auteur, 20 au plus, les plus récemment
 * modifiés d'abord tous types confondus. L'autorisation est appliquée avant de retenir les 20 :
 * des objets invisibles en tête ne masquent pas les objets visibles qui suivent.
 *
 * @param string[] $objets
 * @return list<array{objet: string, id: int, titre: string, raccourci: string}>
 */
function tiptap_spip_rechercher(string $q, array $objets): array {
	include_spip('base/objets');
	include_spip('base/abstract_sql');
	$trouver_table = charger_fonction('trouver_table', 'base');
	$suites = [];
	foreach ($objets as $objet) {
		$table = table_objet_sql($objet);
		$desc = $trouver_table($table);
		if (!$desc) {
			continue;
		}
		// champ titre déclaré par l'objet (« titre, lang », « nom_site AS titre »…) : on garde le premier
		$champ_titre = trim(preg_split('/[\s,]/', (string) ($desc['titre'] ?? 'titre'))[0]);
		if (!isset($desc['field'][$champ_titre])) {
			continue;
		}
		$where = [$champ_titre . ' LIKE ' . sql_quote('%' . addcslashes($q, '%_\\') . '%')];
		if (isset($desc['field']['statut'])) {
			$where[] = "statut != 'poubelle'";
		}
		$suites[] = tiptap_spip_objets_visibles($objet, $table, $champ_titre, isset($desc['field']['maj']), $where);
	}
	return array_map(
		static fn (array $ligne) => [
			'objet' => $ligne['objet'],
			'id' => $ligne['id'],
			'titre' => supprimer_tags(typo($ligne['titre'])),
			'raccourci' => $ligne['objet'] . $ligne['id'],
		],
		tiptap_spip_fusionner_recents($suites, 20)
	);
}

/**
 * Objets d'un type qui vérifient $where, du plus récemment modifié au plus ancien, visibles par
 * l'auteur. Lus par pages de 50, au fur et à mesure que la fusion les demande.
 *
 * @return \Generator<array{objet: string, id: int, titre: string, maj: string}>
 */
function tiptap_spip_objets_visibles(string $objet, string $table, string $champ_titre, bool $avec_maj, array $where): \Generator {
	$id_table = id_table_objet($objet);
	$maj = $avec_maj ? 'maj' : "''";
	$ordre = $avec_maj ? "maj DESC, $id_table DESC" : "$id_table DESC";
	$page = 50;
	$debut = 0;
	do {
		$lignes = sql_allfetsel("$id_table AS id, $champ_titre AS titre, $maj AS maj", $table, $where, '', $ordre, "$debut,$page");
		foreach ($lignes as $ligne) {
			$id = intval($ligne['id']);
			if (autoriser('voir', $objet, $id)) {
				yield ['objet' => $objet, 'id' => $id, 'titre' => (string) $ligne['titre'], 'maj' => (string) $ligne['maj']];
			}
		}
		$debut += $page;
	} while (count($lignes) === $page);
}
```

```php
/**
 * Vrai si $modele est exactement un raccourci de modèle (regex du core, ancrée), avec id ou

 */
function tiptap_spip_est_modele(string $modele): bool {

		&& ($m[2] !== '' || ($m[3] ?? '') !== '');

	return strtolower($m[1]);
}

/**

		if (in_array($nom, $desc['modeles'] ?? [], true)) {

/**
 * Fusionne des suites de lignes triées par `maj` décroissante (date de dernière modification) en
 * une liste des $max plus récentes. Les suites sont lues au fur et à mesure (générateurs) : rien
 * n'est lu au-delà du nécessaire. À `maj` égale, l'ordre des suites départage.
 *
 * @param iterable[] $suites
 * @return array[]
 */
function tiptap_spip_fusionner_recents(array $suites, int $max): array {
	$iterateurs = [];
	foreach ($suites as $suite) {
		$iterateur = $suite instanceof \Iterator ? $suite : new \ArrayIterator(is_array($suite) ? $suite : iterator_to_array($suite, false));
		$iterateur->rewind();
		if ($iterateur->valid()) {
			$iterateurs[] = $iterateur;
		}
	}
	$resultat = [];
	while (count($resultat) < $max && $iterateurs) {
		$meilleur = null;
		foreach ($iterateurs as $k => $iterateur) {
			if ($meilleur === null || strcmp((string) $iterateur->current()['maj'], (string) $iterateurs[$meilleur]->current()['maj']) > 0) {
				$meilleur = $k;
			}
		}
		$resultat[] = $iterateurs[$meilleur]->current();
		$iterateurs[$meilleur]->next();
		if (!$iterateurs[$meilleur]->valid()) {
			unset($iterateurs[$meilleur]);
		}
	}
	return $resultat;
}

/**
 * Liste JSON de chaînes, de 1 à $max éléments d'au plus $longueur caractères chacun ; null sinon.
 *
 * @return string[]|null
 */
function tiptap_spip_liste(?string $json, int $max, int $longueur): ?array {
	$liste = json_decode((string) $json, true);
	if (!is_array($liste) || !array_is_list($liste) || !$liste || count($liste) > $max) {
		return null;
	}
	foreach ($liste as $valeur) {
		if (!is_string($valeur) || $valeur === '' || mb_strlen($valeur) > $longueur) {
			return null;
		}
	}
	return $liste;
}

/**
 * Applique à un texte les traitements SPIP d'un champ, puis safehtml().
 * Reprise de traitements_previsu() du porte-plume (et de markdown_editor), qui peut être absent, avec un
 * contexte de modèle limité à l'objet édité : $contexte vient des arguments signés du formulaire.
 *
 * @param array $contexte  ['objet' => …, 'id_objet' => …] et id_<objet>
 */
function tiptap_spip_traitements_previsu(string $texte, string $nom_champ, string $type_objet, array $contexte = []): string {
	include_spip('public/interfaces');
	include_spip('inc/texte');

	global $table_des_traitements;
	$Pile = [0 => $contexte];
	$ps = $table_des_traitements[$nom_champ] ?? null;
	if (is_array($ps)) {
		include_spip('base/abstract_sql');
		$table = table_objet($type_objet);
		$ps = $ps[(strlen($table) && isset($ps[$table])) ? $table : 0] ?? null;
	}
	if (!$ps) {
		$texte = propre($texte, null, $contexte);
	} else {
		eval('$texte=' . str_replace('%s', '$texte', $ps) . ';');
	}

	// PHP issu des modèles : pas d'eval final ici, contrairement aux pages SPIP
	include_spip('inc/autoriser');
	if (defined('_PROTEGE_PHP_MODELES') && autoriser('previsualiser', 'modelesphp')) {
		$texte = echappe_retour($texte, 'php' . _PROTEGE_PHP_MODELES, 'tiptap_spip_eval_php_modeles');
	}

	// toujours sécuriser : le contenu ne vient pas forcément de l'auteur connecté
	return safehtml($texte);
}

/** Évalue le PHP d'un modèle prévisualisé (cf. tiptap_spip_traitements_previsu()). */
function tiptap_spip_eval_php_modeles($php) {
	ob_start();
	try {
		eval('?>' . $php);
		$texte = ob_get_contents();
	} catch (\Throwable $e) {
		$texte = '<!-- Erreur -->';
	}
	ob_end_clean();
	return $texte;
}
```

```js
/**
 * Contexte serveur d'un textarea (objet, id, champ) pour les hôtes qui ne passent pas par
 * formulaire_fond (spec 02 §6, « Résolution du contexte serveur ») :
 * 1. attributs data-tts-objet, data-tts-id-objet, data-tts-champ posés par le squelette ;
 * 2. formulaire d'un crayon (plugin Crayons) : son nom « objet-champ-id » est dans le champ caché
 *    name_<clé>, le champ édité dans le name du textarea (content_<clé>_<champ>) ;
 * 3. sinon : mode sans objet, champ = name du textarea.
 *
 * @param {HTMLTextAreaElement} textarea
 * @returns {{ objet: string, id: number, champ: string }}
 */
export function contexte(textarea) {
	const { ttsObjet, ttsIdObjet, ttsChamp } = textarea.dataset;
	if (ttsObjet !== undefined) {
		return { objet: ttsObjet, id: Number(ttsIdObjet) || 0, champ: ttsChamp || textarea.name };
	}
	const form = textarea.form;
	if (form?.classList.contains('formulaire_crayon')) {
		for (const input of form.querySelectorAll('input.crayon-id')) {
			const cle = input.value;
			const prefixe = `content_${cle}_`;
			if (!textarea.name.startsWith(prefixe)) continue;
			const nom = form.querySelector(`input[name="name_${CSS.escape(cle)}"]`)?.value ?? '';
			const m = nom.match(/^([a-z_]+)-.*-(\d+)$/);
			if (m) return { objet: m[1], id: Number(m[2]), champ: textarea.name.slice(prefixe.length) };
		}
	}
	return { objet: '', id: 0, champ: textarea.name };
}
```

```js
import { ServiceUnavailable } from './cvt.js';

/**
 * Résultats des services mis en cache côté navigateur : prévisualisations de modèles et titres de
 * liens. Les appels passent par la file de Services (un à la fois, cf. cvt.js).
 *
 * Les services peuvent arriver plus tard (formulaire chargé à la demande, spec 02 §6) : on accepte
 * une promesse de Services, ou null (pas de services : chaque demande est rejetée, et l'affichage
 * garde son repli).
 */

/** @param {import('./cvt.js').Services|Promise<?import('./cvt.js').Services>|null} services */
const disponibles = (services) => Promise.resolve(services).then((s) => {
	if (!s) throw new ServiceUnavailable();
	return s;
});

/** Prévisualisation HTML d'un modèle, par source exacte du raccourci. */
export class ModelPreviews {
	/** @param {import('./cvt.js').Services|Promise<?import('./cvt.js').Services>|null} services */
	constructor(services) {
		this.services = services;
		this.cache = new Map();
	}

	/** @returns {Promise<string>} HTML calculé par SPIP (passé par safehtml) */
	get(source) {
		if (!this.cache.has(source)) {
			const promise = disponibles(this.services).then((s) => s.call('previsu_modele', { modele: source }));
			this.cache.set(source, promise);
			// un échec n'est pas gardé : la prochaine demande repartira au serveur
			promise.catch(() => this.cache.delete(source));
		}
		return this.cache.get(source);
	}
}

/**
 * Titres des liens [->cible]. Les cibles demandées dans le même tour de boucle d'événements partent
 * ensemble, par lots de 50 (limite de verifier()).
 */
export class LinkTitles {
	/** @param {import('./cvt.js').Services|Promise<?import('./cvt.js').Services>|null} services */
	constructor(services, { batch = 50 } = {}) {
		this.services = services;
		this.batch = batch;
		this.cache = new Map();
		this.pending = new Map();
		this.scheduled = false;
	}

	/** @returns {Promise<{ cible: string, titre: ?string, url: ?string, objet: ?string, id: ?number }>} */
	get(cible) {
		if (this.cache.has(cible)) return this.cache.get(cible);
		const promise = new Promise((resolve, reject) => this.pending.set(cible, { resolve, reject }));
		this.cache.set(cible, promise);
		promise.catch(() => this.cache.delete(cible));
		if (!this.scheduled) {
			this.scheduled = true;
			queueMicrotask(() => this.flush());
		}
		return promise;
	}

	flush() {
		this.scheduled = false;
		const demandes = [...this.pending];
		this.pending.clear();
		for (let i = 0; i < demandes.length; i += this.batch) {
			const lot = demandes.slice(i, i + this.batch);
			disponibles(this.services).then((s) => s.call('titre_lien', { cibles: lot.map(([cible]) => cible) })).then(
				(resultats) => {
					const parCible = new Map(resultats.map((r) => [r.cible, r]));
					for (const [cible, { resolve }] of lot) resolve(parCible.get(cible) ?? { cible, titre: null, url: null });
				},
				(erreur) => lot.forEach(([, { reject }]) => reject(erreur)),
			);
		}
	}
}
```

```js
import { serialize } from '../spip/serialize.js';
import { toEditorJSON } from './content.js';

/**
 * Synchronisation textarea ⇄ éditeur (spec 02 §4).
 * Le textarea reste la source de vérité pour la soumission du formulaire : l'éditeur ne fait
 * qu'en produire le contenu, et n'y écrit que si la sérialisation diffère.
 */
export class TextareaBridge {
	/**
	 * @param {{ textarea: HTMLTextAreaElement, editor: import('@tiptap/core').Editor, delay?: number }} options
	 */
	constructor({ textarea, editor, delay = 150 }) {
		this.textarea = textarea;
		this.editor = editor;
		this.delay = delay;
		this.mode = 'visual';
		this.timer = null;
		this.dispatching = false;
		this.sourceDirty = false;

		this.onUpdate = () => this.schedule();
		this.onFlush = () => this.flush();
		this.onInput = () => {
			if (!this.dispatching && this.mode === 'source') this.sourceDirty = true;
		};

		editor.on('update', this.onUpdate);
		editor.on('blur', this.onFlush);
		textarea.addEventListener('input', this.onInput);
		textarea.form?.addEventListener('submit', this.onFlush, true);
		// jquery.form (Crayons, formulaires SPIP en AJAX) sérialise sur un .trigger("submit") jQuery,
		// que l'écouteur natif ne voit pas : il annonce la sérialisation par form-pre-serialize
		const $ = globalThis.jQuery;
		this.$form = $ && textarea.form ? $(textarea.form) : null;
		this.$form?.on('form-pre-serialize.tts', this.onFlush);
		globalThis.window?.addEventListener('beforeunload', this.onFlush);
	}

	schedule() {
		clearTimeout(this.timer);
		this.timer = setTimeout(this.onFlush, this.delay);
	}

	/** Écrit la sérialisation dans le textarea si elle diffère, avec événements input et change. */
	flush() {
		clearTimeout(this.timer);
		this.timer = null;
		if (this.mode !== 'visual' || this.editor.isDestroyed) return;
		const value = serialize(this.editor.getJSON());
		if (value === this.textarea.value) return;
		this.textarea.value = value;
		this.dispatching = true;
		try {
			this.textarea.dispatchEvent(new Event('input', { bubbles: true }));
			this.textarea.dispatchEvent(new Event('change', { bubbles: true }));
		} finally {
			this.dispatching = false;
		}
	}

	/** Recharge l'éditeur depuis le textarea, sans émettre de mise à jour (pas de réécriture). */
	load() {
		const json = toEditorJSON(this.textarea.value, this.editor.schema);
		this.editor.commands.setContent(json, { emitUpdate: false });
	}

	/**
	 * Bascule visuel ⇄ source. Au retour en visuel, l'éditeur est rechargé une seule fois si la
	 * source a changé. Renvoie false si la source n'est pas représentable (on reste en source).
	 * @param {'visual'|'source'} mode
	 * @returns {boolean}
	 */
	setMode(mode) {
		if (mode === this.mode) return true;
		if (mode === 'source') {
			this.flush();
			this.mode = 'source';
			this.sourceDirty = false;
			return true;
		}
		if (this.sourceDirty) {
			try {
				this.load();
			} catch (error) {
				console.warn('tiptap_spip : source non représentable, mode source conservé', error);
				return false;
			}
		}
		this.mode = 'visual';
		this.sourceDirty = false;
		return true;
	}

	destroy() {
		this.flush();
		this.editor.off('update', this.onUpdate);
		this.editor.off('blur', this.onFlush);
		this.textarea.removeEventListener('input', this.onInput);
		this.textarea.form?.removeEventListener('submit', this.onFlush, true);
		this.$form?.off('form-pre-serialize.tts', this.onFlush);
		globalThis.window?.removeEventListener('beforeunload', this.onFlush);
		this.editor.destroy();
	}
}
```

```js
/**
 * Monte l'éditeur sur les textareas équipés de `racine` (document par défaut). Idempotent :
 * appelée au chargement puis à chaque onAjaxLoad (rechargements AJAX de SPIP et Crayons).
 *
 * @param {ParentNode|ParentNode[]|{ jquery: string }} [racine]
 * @param {{ createEditor?: typeof defaultCreateEditor }} [options]
 */
export function tiptap_spip_init(racine = document, { createEditor = defaultCreateEditor } = {}) {
	const sel = selecteur();
	const textareas = new Set();
	for (const root of racines(racine)) {
		if (root.matches?.(sel)) textareas.add(root);
		root.querySelectorAll(sel).forEach((t) => textareas.add(t));
	}
	for (const textarea of textareas) {
		if (textarea.dataset.ttsMounted || textarea.matches(MARKDOWN_EDITOR)) continue;
		textarea.dataset.ttsMounted = 'oui';
		releasePortePlume(textarea);
		try {
			instances.add(new Instance(textarea, { createEditor }));
		} catch (error) {
			textarea.dataset.ttsMounted = 'erreur';
			console.warn('tiptap_spip : éditeur non monté, le textarea reste en saisie directe', error);
		}
	}
	if (instances.size) watchRemovals();
}

/**
 * Racines où chercher : onAjaxLoad passe la racine rechargée dans this, parfois sous forme d'objet
 * jQuery ou de tableau d'éléments (Crayons : triggerAjaxLoad(tous.get())).
 */
function racines(racine) {
	const liste = racine?.jquery || Array.isArray(racine) ? Array.from(racine) : [racine];
	const noeuds = liste.filter((n) => n?.querySelectorAll);
	return noeuds.length ? noeuds : [document];
}
```
